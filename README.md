# XXTouch Express Barcode Generator (XXTouch 屏幕快递单号识别与 CODE128 条形码批量生成工具)

基于 **XXTouch Elite (iOS)** 框架开发的高性能自动化脚本。支持对当前手机屏幕进行实时 OCR 文字识别，精准抽取合法的快递单号，并自动生成符合工业与商业标准的 **CODE128** 条形码保存至系统相册或弹出浮窗对屏扫描。

---

## 🌟 核心特性

- **高效屏幕 OCR 识别**：原生调用 XXTouch `screen.ocr_text` 接口，无缝截屏与文字解析。
- **高精度正则与业务过滤**：
  - 正则模式：`\b(?!(?:1[3-9]\d{9}))(?!(?:\d{17}[\dXx]))([A-Za-z0-9]{10,18})\b`
  - 严格限定 ASCII 字符集 `[A-Za-z0-9]`，杜绝 iOS/Darwin 底层多字节中文字符造成的编码异常。
  - 自动剔除 11 位大陆手机号及 18 位身份证号。
  - 内置业务强特征过滤（至少包含 6 位数字），自动过滤系统英文 UI 词汇（如 `Notifications`、`Preferences`）。
- **CODE128 Auto 自适应编码**：
  - 偶数位纯数字：自动启用 **Code 128C** 双数字压缩，条码长度减半，大幅提升扫描枪读取成功率与对焦速度。
  - 奇数位纯数字（如 15 位单号）/ 字母组合（如 `SF...`、`JT...`）：智能无缝切换 **Code 128B**。
- **商业标准工业条形码排版**：
  - 纯白背景 (`#ffffff`)，无任何外边框与杂乱装饰。
  - 上方高对比度纯黑条码，下方居中排列深黑单号文字 (`0x222222`)。
  - 精确还原 **1024 × 400 (约 2.57 : 1)** 黄金比例，带标准上下左右 Quiet Zone（静区留白）。
- **全量批量静默导出 (方案 B)**：
  - 屏幕上有多个单号时全自动并发导出，无阻塞式弹窗打扰。
  - 自动汇总所有单号至 iOS 系统剪贴板（换行分隔）。
  - 轻量瞬时 `sys.toast` 提示与完备的 `nLog` 日志跟踪，单项循环独立容错。

## 🚀 部署与使用方法

### 1. 环境准备
- 运行环境：安装有 **XXTouch / XXTouch Elite** 的 iOS 设备（越狱环境或 TrollStore 巨魔环境）。
- 系统版本：iOS 14.0 ~ 16.x+。

### 2. 脚本传输
- **方式一（电脑端 Web 传输）**：
  1. 确保手机与电脑在同一局域网内；
  2. 电脑浏览器访问 `http://<设备IP>:46952` 打开 XXTouch 控制台；
  3. 将 `BatchBarcodeExport.lua` 上传至设备脚本根目录。
- **方式二（VS Code 插件）**：
  - 使用 VS Code 的 XXTouch 扩展插件，一键远程推流并触发运行。

### 3. 执行脚本
1. 在手机上打开任意包含快递单号的界面（如菜鸟裹裹、极兔速递、拼多多、淘宝订单列表、微信物流消息等）；
2. 触发运行 `BatchBarcodeExport.lua`；
3. 打开系统**“照片”**相册，即可查看批量生成的条形码；
4. 系统剪贴板中已同步复制所有识别出的单号文本。

## 🛠️ 技术规格参数

| 参数项 | 配置值 | 说明 |
| :--- | :--- | :--- |
| 编码标准 | CODE128 (Auto: B/C 自动切换) | 模 103 校验和计算 |
| 单点单元宽度 (`module_w`) | 6 px | 保证高清晰度与长条形比例 |
| 条形码高度 (`bar_h`) | 225 px | 黄金比例高度 |
| 顶部/底部留白 | 60 px / 55 px | 符合扫描器静区规范 |
| 画布尺寸 | 约 1024 × 402 px | 2.57:1 标准长宽比 |
| 文字字号与颜色 | 32.0 px / `0x222222` | 无黑框纯白底色渲染 |
